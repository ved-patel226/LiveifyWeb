## The problem

There aren't always songs that have been performed live!!!

Especially unreleased songs, which are often the best ones. 

We need a way to convert studio recordings into live performances, so we can enjoy the best versions of our favorite songs!


## The Solution

Create a neural network that can take in a studio recording and output a live performance version of the song!
Aka. Liveify!
